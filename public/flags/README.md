# Country flags

SVG flags (4x3 ratio), named by lowercase ISO 3166-1 alpha-2 country code (e.g. `om.svg` for Oman).

Vendored from the [flag-icons](https://www.npmjs.com/package/flag-icons) project (MIT license), v7.5.0
— the actively maintained successor to `flag-icon-css`. To update, download a newer release and
replace the files in this folder; filenames match `country_code` on the `countries` table.
